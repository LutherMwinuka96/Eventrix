⚠️ Important: This application requires XAMPP/Apache server, not Live Server extension!

🚀 Quick Setup Steps

  1. Install XAMPP from apachefriends.org
  2. Start XAMPP Control Panel
  3. Start Apache and MySQL services
  4. Copy Miriamu folder to C:\xampp\htdocs\
  5. Open browser to http://localhost/Miriamu/
  6. Setup database using manual configuration
  7. Test registration and login functionality
